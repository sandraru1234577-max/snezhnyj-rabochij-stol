# Снежный рабочий стол ❄️

Снег на рабочем столе Windows: сугробы растут на окнах, панели задач и
виджетах, с закрытых окон снег сходит каскадом снежных комьев (по формулам
кинематики — честное скольжение по кромке, свободное падение, «всплеск» при
приземлении), красный трактор-снегоуборщик периодически прочищает низ экрана,
а из трёх снежков можно слепить снеговика с шарфом, ведром и руками-палочками.

Идея вдохновлена [tryflake.ru](https://tryflake.ru/#how).


## Установка и запуск

### Вариант 1 — exe (ничего не нужно)

1. Скачай `SnezhnyStol.exe` из [Releases](../../releases) (28 МБ).
2. Двойной клик — снег идёт. Python и права администратора не нужны.
3. При **первом** запуске Windows покажет синее окно SmartScreen
   («Windows защитил ваш компьютер») — это нормально для файлов без
   цифровой подписи: нажми **«Подробнее» → «Выполнить в любом случае»**.
   Второй раз предупреждения не будет.

Пока программа запущена — снег идёт. Закрыть: клавиша **ESC** (или убить
процесс `SnezhnyStol.exe` в Диспетчере задач).

### Вариант 2 — из исходников (для разработки)

```
pip install pygame pywin32
python snezhnyj_rabochij_stol.py
```

Требуется Python 3.10+ на Windows.

## Управление

| Клавиша | Действие |
|---|---|
| ← → (удерживать) | ветер: снег наклоняется в сторону |
| ↑ (удерживать) | снежок у курсора появился и растёт |
| ↓ (удерживать) | снежок уменьшается / исчезает |
| ЛКМ | положить снежок на это место |
| колесо мыши | запасной способ растить снежок |
| F8 | убрать весь снег со всего экрана |
| ESC | выключить программу и выйти |

Все клавиши — «на удержание»: держишь — действие идёт. Снежки кладутся
навсегда (пока не сметёт трактор или F8).

**Снеговик**: положи три снежка рядом (примерно вплотную) — они
соберутся в снеговика ⛄ с ведром, шарфом и деревянными руками. Размер
снеговика зависит от размеров снежков — пробуй разные.

## Как всё работает

### Снегопад и намёт

- Снежинки падают по всему экрану как плотные комки:
  у каждой свой размер (2–3 px), скорость и лёгкое покачивание.
- При приземлении снег **распределяется на соседние колонки** (50% в точку,
  по 22% соседям, по 3% дальним) — сугробы нарастают ровно, без кочек.
- Внизу экрана **всегда есть базовая полоска снега** (~14 px): даже после
  чистки трактором или F8 она восстанавливается за секунду.
- Ветер (стрелки ← →) меняет наклон снегопада в сторону.

### Сугробы на окнах

- На верхней кромке **каждого видимого окна** (включая проводник, браузер,
  панель задач — она ловится по классу `Shell_TrayWnd`) копится бугристый
  слой снега с пушистой поверхностью.
- Снежный слой привязан к окну: двигаешь окно — сугроб едет вместе с ним.
- У краёв слоя — плавный провис вниз, как снег на карнизе.
- Список окон обновляется каждую секунду отдельным потоком — даже
  «зависающее» окно проводника не тормозит анимацию.

### Сход снега при закрытии окна

Когда окно закрывается, его сугроб не исчезает — он **сыплется вниз**,
и движение считается по честной физике (кинематика тела, срыва с кромки):

1. **Скольжение по кромке**: `a = g·(-µ·cos α)` — ускорение кома
   зависит от крутизны кромки и трения снега.
2. **Срыв с края**: скорость `v₀ = √(2aL)` — сколько ком проехал
   по скату, такую скорость и унёс.
3. **Полёт после срыва**: `x(t) = x₀ + v₀ₓ·t`, `y(t) = y₀ + v₀_y·t + g·t²/2`.
4. **Приземление**: время до земли — корень квадратного уравнения
   `t = (−v₀y + √(v₀y² + 2g·h)) / g`, где h — расстояние до сугроба
   внизу с учётом уже наметённого снега.

Каждый из ~48 комьев имеет свой угол, трение, скорость — осыпь выглядит
живой, а не строем. Приземлившись, ком не исчезает, а **долепляется в
сугроб «всплеском»**: основная масса в точке удара, вытянутый «язык»
дальше по направлению полёта, лёгкий след позади.

**Если закрыть несколько окон подряд** (с разрывом до ~6 секунд) и они
перекрываются по ширине — снег сольётся в **один общий каскад**, а не
сыплется от каждого окна отдельно.

### Трактор-снегоуборщик 🚜

Красный трактор с живым валиком снега перед отвалом выезжает, когда:

| Триггер | Условие |
|---|---|
| `timer` | каждые 2 минуты работы |
| `snowgrown` | средняя высота сугробов внизу > 30 px |
| `freshdrops` | со вкладок надолёпилось много снега (порог ≈ 1 окно) |

Выезжает **с той стороны экрана, где снега больше**. Едет по сугробам
(поднимается и опускается по рельефу), счищает снег перед отвалом и под
собой — за ним остаётся расчищенная колея, которая снова затягивается
снегом. После проезда таймер стартует с нуля, и через 2 минуты (или
раньше — если снег накопился) он приедет снова.

Причина каждого выезда пишется в лог (см. ниже).

### Производительность

- 16 кадров/сек — глазу не отличить от 30, но CPU ~3–4% вместо 21%.
- Опрос чужих окон — в отдельном потоке (не замораживает основную
  анимацию, если Explorer «тупит»).
- Спрайты снежков и снеговиков кэшируются.
- Одновременно работает **только одна копия** (мьютекс): повторный запуск
  тихо выходит, снег не плодится и не греет ноут двумя процессами.

## Логи и диагностика

Ошибки и выезды трактора пишутся в `%APPDATA%\snezhnyj_stol\snow.log`
(если запущено из exe). Если «что-то не работает» — сначала посмотри,
живой ли процесс `SnezhnyStol.exe` в Диспетчере задач, потом лог.

Частые случаи:

| Симптом | Причина |
|---|---|
| SmartScreen при запуске | «Подробнее» → «Выполнить в любом случае» (первый раз только) |
| Двойной клик — ничего не происходит | Уже запущено (мьютекс) — проверь трей/Диспетчер, там один `SnezhnyStol.exe` |
| Антивирус ругается | Ложное срабатывание на упаковку PyInstaller — исключение вручную |
| Ноутбук греется | Проверь, что не запущено 2+ копий; если одна — это максимум ~4% CPU |

## Сборка exe из кода

```
pip install pyinstaller
pyinstaller --noconsole --onefile --name SnezhnyStol snezhnyj_rabochij_stol.py
```

Готовый файл — `dist/SnezhnyStol.exe`. При запуске из exe логи пишутся
в `%APPDATA%` автоматически.

## Совместимость

Windows 10/11 x64 (используются win32api: системные крючки ввода,
панель задач `Shell_TrayWnd`, прозрачное окно поверх рабочего стола
с пролазом кликов сквозь). Mac и Linux не поддерживаются — там нужны
свои механизмы оконного слоя.
